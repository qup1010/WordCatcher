# Word Catcher

浏览器划词 → **快速翻译**（免费即时）或 **AI 语境详解** → 看完再决定存不存 → 一键进 Anki。

采集归浏览器，复习归 Anki。这个扩展只做前半段，不重复造单词本、记忆曲线和复习界面。

## 它和现成方案的区别

| | 沙拉查词 | Read Frog | Word Catcher |
|---|---|---|---|
| 快速机器翻译 | ✅ | ✅ | ✅（微软/谷歌，免配置） |
| AI 语境释义 | ❌ | ✅ | ✅ |
| 保存原句 | ✅ | ✅ | ✅ |
| 原句挖空复习 | ✅ | ❌ | ✅ |
| 单词本存在哪 | 本地 | 官方服务器 | 你自己的 Anki |

核心取舍：**释义交给 AI，快速查词交给免费机器翻译，存储和复习交给 Anki**，中间那段自己写。

## 装之前：先把 Anki 装好

扩展本身不存单词，所有卡片直接写进你本地的 Anki，所以这一步是前置条件。

1. 装 [Anki 桌面版](https://apps.ankiweb.net/)（Windows 版即可，不是手机版、不是 AnkiWeb）。
2. 装 AnkiConnect 插件：打开 Anki →「工具 → 附加组件 → 获取附加组件」→ 输入代码 **`2055492159`** → 确定 → 重启 Anki。
3. 用之前保持 Anki 在后台运行。它没开的时候，扩展仍能划词查询，只是存不了卡。

AnkiConnect 会在 `127.0.0.1:8765` 起一个本地 HTTP 服务，扩展就是通过它建卡的。这个服务只绑定本机，不对外网开放。

## 装扩展

```bash
pnpm install
pnpm build
```

然后打开 Chrome/Edge 的 `chrome://extensions`，开启右上角「开发者模式」，点「加载已解压的扩展程序」，选中 `.output/chrome-mv3` 目录。

首次安装会自动弹出设置页。

## 配置

**AI 接口**：任何 OpenAI 兼容的服务都行，设置页里内置了 OpenAI、DeepSeek、Kimi、智谱、硅基流动、OpenRouter、本地 Ollama 的地址预设，选一个再填 API key 即可。

> 释义质量直接取决于模型。太小的模型可能不支持结构化输出，表现为一直报错——换个大一点的模型即可。

**Anki**：默认写入名为 `Word Catcher` 的牌组，不存在会自动创建。点「测试连接并同步卡片模板」验证是否打通。

**学习语言**：同时决定插件内试听的发音，和 Anki 卡片里 `{{tts}}` 标签的朗读语音。

## 用法

在任意网页划选一个词，出现两个按钮：

**快速翻译（闪电按钮）** —— 免费、即时、不消耗 AI 额度。适合只想快速看一眼意思。微软/谷歌可选（默认微软，各种网络环境都能用），首选连不上时自动切换另一家。迷你面板里可随时点「AI 详解」升级。

**AI 详解（星光按钮）** —— 面板里给出：

- 词条原形（时态、复数已还原）
- IPA 音标 + 试听按钮
- **这个词在这句话里**的意思，不是词典义项罗列
- 原句（目标词高亮）+ 整句翻译

看完觉得值得收藏，再点「存入 Anki」。不想要就直接关掉，什么都不会留下。

按 `Esc` 或点击别处随时关闭。

## 卡片长什么样

正面是**挖空的原句**：

> He was `[ ? ]` by the news.
> *v.*

背面才揭晓答案，并自动朗读：

> **devastate** /ˈdevəsteɪt/ （自动朗读）
> 使极度震惊、悲痛
> He was devastated by the news.
> 这个消息让他极度震惊。
> [来源页面链接]

在语境里回忆一个词，比干背「单词 → 释义」有效得多。这也是保留原句最大的意义——不喜欢可以在设置里关掉。

朗读用的是 Anki 内置的 `{{tts}}` 标签，不下载、不存储任何音频文件。

## 故障排查

**「连不上 Anki」**

1. 确认 Anki 桌面版正在运行。
2. 确认 AnkiConnect 已安装（工具 → 附加组件，列表里应有 AnkiConnect）。
3. 仍然失败的话：选中 AnkiConnect →「配置」→ 在 `webCorsOriginList` 数组里加一行 `"*"` → 重启 Anki。

扩展从 background 发请求、且已声明主机权限，通常不受 CORS 限制，多数情况下不需要第 3 步。

**「这个词已经在牌组里了」**

按笔记的首个字段（Word）查重，同一个词第二次划到会被 Anki 拒绝，属正常行为。

**改了学习语言，但 Anki 卡片还念旧的**

去设置页点一次「测试连接并同步卡片模板」，模板里的 `{{tts}}` 语言会被刷新。

## 开发

```bash
pnpm dev          # 开发模式，自动重载
pnpm compile      # 类型检查
pnpm test         # 单元测试
pnpm test:cov     # 带覆盖率
pnpm build        # 生产构建
```

代码组织：

```
lib/
  selection-context.ts   划词 → 原句抽取（整个项目最核心也最易错的部分）
  ai.ts                  OpenAI 兼容调用 + 结构化输出
  machine-translate.ts   免费机器翻译（微软 Edge token 带缓存与并发去重，谷歌 gtx，自动回退）
  anki.ts                AnkiConnect 客户端、笔记类型、挖空
  settings.ts            配置读写与向后兼容
  tts.ts                 Web Speech API 试听
entrypoints/
  content/               划词工具栏与词条面板（Shadow DOM 隔离）
  background.ts          消息中枢，AI 与 Anki 请求都在这里发
  options/               设置页
  popup/                 状态面板
```

**为什么原句由 DOM 抓、不让 AI 复述**：挖空需要目标词和原句严格对齐，AI 一旦改写句子（哪怕只是改个标点），挖空就会失配。所以 `lib/ai.ts` 的输出 schema 里刻意不包含原句。
