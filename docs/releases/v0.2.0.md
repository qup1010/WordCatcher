# Word Catcher 浏览器插件 v0.2.0

本次更新扩展本地单词本，让查到的词和原句可以长期整理、复习，并方便在浏览器插件与 Windows 桌面版之间手动迁移。

## 更新内容

- 单词本支持按词聚合多条语境、搜索、编辑、删除、重开 AI 分析及逐条同步 Anki。
- 新增单词本复习模式，可朗读词条、随机排列卡片并切换答案显示。
- 支持单词本 JSON 导入和导出。导入会补入尚不存在的语境，不覆盖已有记录；插件与桌面版之间可通过备份文件手动迁移单词本。
- 重新整理设置分区，集中管理单词本备份、配置备份、Anki 待同步队列和桌面端联动。
- 改进侧边栏对网页查词上下文的承接和语境编辑，并调整弹窗、查词卡片与设置页的布局。

## 下载与安装

Chrome / Edge：下载 `word-catcher-0.2.0-chrome.zip`，解压后在扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。更新后刷新阅读页面。

Firefox：下载 `word-catcher-0.2.0-firefox.zip`，通过 `about:debugging` 临时加载；重启后需要重新加载。该压缩包不是已签名的长期安装包，当前侧边栏入口也不适用于 Firefox。
