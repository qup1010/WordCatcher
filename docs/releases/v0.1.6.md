# Word Catcher 浏览器插件 v0.1.6

本次补丁优化离线词典的词义顺序与卡片排布，并与 Windows 桌面版统一阅读体验。

## 更新内容

- 将查词卡片、侧边栏及历史记录中的「存入 Anki」统一为「保存」，成功状态显示「已保存」。
- 普通词义优先，姓名和专名靠后；修复多个核心义项顺序反转，按核心、常用、少见义稳定排序。
- 统一展示与保存摘要，保留全部有效词性；同一词性的摘要用分号连续显示，按可用宽度自然换行。
- 网页浮窗与侧边栏共用词典视图，补齐学习解释、例句翻译和用法提示。默认显示一条例句，其余可展开。
- 「完整释义」入口紧随摘要，原句在前、记忆线索在后，避免重复解释。

## 下载与验证

Chrome / Edge：下载 `word-catcher-0.1.6-chrome.zip`，解压后重新加载扩展，并刷新阅读页面。

Firefox：下载 `word-catcher-0.1.6-firefox.zip`，通过 `about:debugging` 临时加载。重启后需要重新加载，侧边栏入口暂不适用；此包不是已签名的长期安装包。

发布前类型检查、195 项自动测试和双浏览器构建通过；已使用隔离演示数据检查真实浮窗、侧边栏以及详情、更多例句交互。保存仍沿用已有 Anki 写入或离线暂存流程，本次仅简化操作文案。
