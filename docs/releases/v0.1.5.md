# Word Catcher 浏览器插件 v0.1.5

本次更新细化网页查词、工具栏弹窗和侧边栏体验，改善阅读中的反馈与查询可靠性。

## 更新内容

- 优化查词卡片的词义层级、按钮、展开区域和状态反馈，同时打磨弹窗及侧边栏视觉与文案。
- 改善手动查询的语境重置、异步结果顺序与 AI 请求取消，减少快速切换查询时旧结果覆盖新结果的问题。
- 改善历史记录、保存反馈与键盘操作体验。
- 整理测试目录及忽略规则，重写用户说明，补充 Windows 桌面版介绍与新版展示图。

## 下载与安装

Chrome / Edge：下载 `word-catcher-0.1.5-chrome.zip`，解压后在扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。更新后刷新阅读页面。

Firefox：下载 `word-catcher-0.1.5-firefox.zip`，通过 `about:debugging` 临时加载；重启后需要重新加载。该压缩包不是已签名的长期安装包，当前侧边栏入口也不适用于 Firefox。

离线词典、在线快译与 AI 语境详解仍可按需使用，Anki 集成为可选功能。配置与记录不会自动与桌面版互通。

## 验证范围

发布前类型检查与 191 项自动测试通过，Chrome / Firefox 发布压缩包均构建成功。
