# Word Catcher 浏览器插件 v0.2.1

本次更新加入手动句子翻译，并改进语境切换、编辑和翻译缓存相关请求的可靠性。

## 更新内容

- 查词结果和已保存的学习语境支持手动翻译原句。
- 切换语境或记录后忽略过期响应，避免旧结果覆盖当前界面内容。
- 编辑时合并最新的学习记录，保存失败时向用户显示反馈。
- 翻译设置变化后清理缓存，并阻止旧请求结果重新写入。

## 下载与安装

Chrome / Edge：下载 `word-catcher-0.2.1-chrome.zip`，解压后在扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。

Firefox：下载 `word-catcher-0.2.1-firefox.zip`，通过 `about:debugging` 临时加载；重启后需要重新加载。该压缩包不是已签名的长期安装包，当前侧边栏入口也不适用于 Firefox。

## 验证范围
