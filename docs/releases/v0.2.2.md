# Word Catcher 浏览器插件 v0.2.2

- 优化设置页的语言和首次使用指引，区分自动保存的偏好与需要手动保存的连接配置。
- 改进离线词典、AI、Anki、备份和同步设置的状态反馈与操作说明。
- 同步冲突时可对比两端内容并选择保留本地或云端版本。
- 优化查词和侧边栏交互，避免较早的请求结果覆盖当前内容。

## 下载与安装

Chrome / Edge：下载 `word-catcher-0.2.2-chrome.zip`，解压后在扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。

Firefox：下载 `word-catcher-0.2.2-firefox.zip`，通过 `about:debugging` 临时加载；重启后需要重新加载。该压缩包不是已签名的长期安装包，当前侧边栏入口也不适用于 Firefox。

## 验证范围

发布工作流会运行 TypeScript 检查、自动化测试，并构建 Chrome 与 Firefox 发布压缩包。
